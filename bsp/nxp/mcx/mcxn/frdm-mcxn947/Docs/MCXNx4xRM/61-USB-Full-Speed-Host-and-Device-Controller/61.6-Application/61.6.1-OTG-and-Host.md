## 61.6.1 OTG and Host mode operation

The Host mode logic allows portable, mobile, and other devices using this chip to function as a USB-embedded host (EH) controller. The OTG logic adds an interface to allow the OTG host negotiation and session request protocols (HNP and SRP) to implement in software. 

Host mode is used in handheld-portable devices to connect simple HID class devices like printers and keyboards easily. It is not intended to perform the functions of a full OHCI or UHCI-compatible host controller found on PC motherboards. Host mode allows bulk, isochronous, interrupt, and control transfers. Perform bulk data transfers at nearly the total USB interface bandwidth. Support is provided for ISO transfers, but the number of ISO streams you can practically support is affected by the interrupt latency of the processor servicing the Token Done interrupts from the SIE. You must write custom drivers to support host mode operation. 

The USBFS core can only operate as a peripheral device or in Host mode; the USBFS core cannot operate simultaneously in both peripheral device and Host modes. Writing 1 to CTL[HOSTMODEEN] enables Host mode. When Host mode is enabled, use the endpoint zero only. You must disable all other endpoints.
