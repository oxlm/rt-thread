## 61.3.4.3 Keep-Alive mode

Keep Alive mode is for the chips operating with Device-only USB use cases. 

## NOTE

The address range 48010000h to 480101FFh consists of 512 bytes of on-chip USB RAM, which is available in Active or Sleep modes. This allows the USB core to access the USB RAM in Keep Alive Mode. 

When entering Keep Alive Mode, you must place the BDT entries and all USB buffers accessed during Keep Alive mode in the USB RAM space 

Keep Alive mode keeps USB basic response functionality active in the Sleep low-power mode, so there is no need to re-enumerate the USB device after exiting that Low-Power mode. When connected to the host and when there is no data to transfer, to save power, the software can power down the system bus and the CPU, keeping only the USB power on. In Keep Alive mode, only the USB 48 MHz functional clock is required by the USB controller; the rest of the device can transition to Sleep mode. When the SETUP token or a software-assigned token is received, the USB core wakes up, but it responds with NAK to all other types of packets. 

Because the USB core must access the BDT in Keep Alive mode, use the on-chip USB RAM for the BDT and small data packets during Keep Alive mode. Place the BDT into this RAM in Keep Alive mode and changes all OWN fields to 0 (except the SETUP endpoint). You can do this by writing 1 to KEEP_ALIVE_CTRL[OWN_OVERRD_EN].
