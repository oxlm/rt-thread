## 61.3.4.3.2 Exiting Keep-Alive mode

Any enabled interrupt generates a wakeup from Sleep mode; this causes an exit from USB Keep Alive mode. You can also configure the USB to generate an interrupt when it receives a particular token (for example, SETUP), as configured by KEEP_ALIVE_WKCTRL[WAKE_ON_THIS]. Other USB interrupts can also remain enabled and are generated in USB Keep-Alive mode.
