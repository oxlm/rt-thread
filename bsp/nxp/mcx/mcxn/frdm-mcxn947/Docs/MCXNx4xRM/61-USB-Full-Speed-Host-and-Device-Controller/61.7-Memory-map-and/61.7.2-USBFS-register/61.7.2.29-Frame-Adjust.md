## 61.7.2.29 Frame Adjust (USBFRMADJUST)

Offset 

<table><tr><td>Register</td><td>Offset</td></tr><tr><td>USBFRMADJUST</td><td>114h</td></tr></table>

## Function

Allows adjustment of frame counting interval for the Host mode operation.

Fields 

<table><tr><td>Field</td><td>Function</td></tr><tr><td>7-0</td><td>Frame Adjustment</td></tr><tr><td>ADJ</td><td>Specifies that in Host mode, the frame adjustment is a two&#x27;s complement number that adjusts the period of each USB frame in 12 MHz clock periods. A SOF is normally generated every 12,000 cycles of a 12 MHz clock. Frame Adjust (USBFRMADJUST) can adjust this by -128 to +127, to compensate for inaccuracies in the USB 48 MHz clock. Changes to this field take effect at the start of the next frame.</td></tr></table>
