## 61.3.4.1 Active mode

This is the basic mode of operation. The USBFS core uses software control to switch between two modes of operation: 

• USB peripheral device 

• USB host 

In either mode, the USB host or USB peripheral device uses the same data paths and BDs for the transmission and reception of data. For this reason, use a USBFS core-centric nomenclature to describe the direction of the data transfer between the USBFS core and USB: 

• Receive (or "Rx") describes transfers that move data from USB to memory. 

• Transmit (or "Tx") describes transfers that move data from memory to USB.
