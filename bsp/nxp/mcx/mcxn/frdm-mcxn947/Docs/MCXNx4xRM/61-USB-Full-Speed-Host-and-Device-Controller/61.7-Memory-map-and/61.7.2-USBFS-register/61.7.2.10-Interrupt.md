## 61.7.2.10 Interrupt Status (ISTAT)

Offset 

<table><tr><td>Register</td><td>Offset</td></tr><tr><td>ISTAT</td><td>80h</td></tr></table>

## Function

Contains flag fields for each of the interrupt sources within USBFS. Each of these fields is qualified with their respective interrupt enable fields. 

All fields of this register are logically OR'd together, along with OTG Status (OTGSTAT), to form a single interrupt source for the processor's interrupt controller.
