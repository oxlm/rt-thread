## 61.7.2.20 Token (TOKEN)

Offset 

<table><tr><td>Register</td><td>Offset</td></tr><tr><td>TOKEN</td><td>A8h</td></tr></table>

## Function

Initiates USB transactions when in Host mode (CTL[HOSTMODEEN] = 1). 

When you execute a USB transaction to a peripheral, it writes the TOKEN type and endpoint to Token (TOKEN). After you wrote to Token (TOKEN), USBFS begins the specified USB transaction to the address contained in the address register. 

Before writing to Token (TOKEN), the processor core must always check that the TOKEN_BUSY in the control register is not 1. This ensures that the token commands are not overwritten before you can execute them. 

Use Address (ADDR) and Endpoint Control (ENDPT0 - ENDPT15) when performing a token command and must write before Token (TOKEN) 

Address (ADDR) selects the USB peripheral address, which the token command transmits. 

Endpoint Control (ENDPT0 - ENDPT15) determines the handshake and retries policies used during the transfer.
