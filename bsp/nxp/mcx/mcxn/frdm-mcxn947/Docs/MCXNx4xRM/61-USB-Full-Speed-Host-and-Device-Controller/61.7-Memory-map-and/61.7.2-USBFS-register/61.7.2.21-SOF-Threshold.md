## 61.7.2.21 SOF Threshold (SOFTHLD)

Offset 

<table><tr><td>Register</td><td>Offset</td></tr><tr><td>SOFTHLD</td><td>ACh</td></tr></table>

## Function

This register is used only in Host mode (CTL[HOSTMODEEN] = 1). The 14-bit SOF counter counts the interval between SOF frames when in Host mode. You must transmit the SOF every 1 ms, so load the SOF counter with a value of 12000. When the SOF counter reaches zero, a SOF token is transmitted. This register programs the number of USB byte times when MISCCTRL[SOFDYNTHLD] = 0 (or 8-byte times when MISCCTRL[SOFDYNTHLD] = 1), before the SOF stops initiating token packet transactions. 

Write a value to SOFTHLD[CNT] that ensures that other packets are not actively transmitted when the SOF time counts to zero. After the SOF counter reaches the threshold value, no more tokens are transmitted until after the SOF has been transmitted. The value programmed into the threshold register must reserve enough time to ensure that the worst-case transaction finishes. In general, the worst-case transaction is an IN token, followed by a data packet from the peripheral device and the host's response. The actual time required is a function of the maximum packet size on the bus. Typical values for the SOF threshold are: 

• 74 for 64-byte packets 

• 42 for 32-byte packets 

• 26 for 16-byte packets 

• 18 for 8-byte packets
