## 61.7.2.6 OTG Interrupt Status (OTGISTAT)

Offset 

<table><tr><td>Register</td><td>Offset</td></tr><tr><td>OTGISTAT</td><td>10h</td></tr></table>

## Function

Records changes to the state of the 1-millisecond timer and line state stable logic. 

You can read this register to determine the event that triggers an interrupt. 

Only fields that have changed since the last read becomes 1.
