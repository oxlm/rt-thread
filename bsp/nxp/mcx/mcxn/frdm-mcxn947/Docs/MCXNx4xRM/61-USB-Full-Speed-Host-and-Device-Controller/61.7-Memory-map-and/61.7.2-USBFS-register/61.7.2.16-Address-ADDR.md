## 61.7.2.16 Address (ADDR)

Offset 

<table><tr><td>Register</td><td>Offset</td></tr><tr><td>ADDR</td><td>98h</td></tr></table>

## Function

• In Peripheral mode (CTL[HOSTMODEEN] = 0), this register holds the unique USB address that USBFS decodes. In Host mode (CTL[HOSTMODEEN] = 1), USBFS transmits this USB address with a TOKEN packet. This enables USBFS to uniquely address any USB peripheral. In both Peripheral or Host mode: CTL[USBENSOFEN] must be 1. 

• After the reset input becomes active or USBFS decodes a USB reset signal, this register resets to 00h. This action initializes this register to decode address 00h, as required by the USB specification.
