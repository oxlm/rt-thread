## 61.6.4 OTG operation

The USB-OTG core provides sensors and controls to enable On-The-Go (OTG) operation. The OTG driver software uses these sensors to implement the host negotiation protocol (HNP) and session request protocol (SRP) and to give access to the OTG protocol control signals.
