## 61.3.4.3.1 Entering Keep-Alive mode

## To enter Keep-Alive mode:

## 1. To configure the USB subsystem for Keep-Alive mode before entering Sleep mode:

• Initialize the BDT in USB RAM, including writing 0 to the OWN field within each BDT entry for every endpoint except for EP0. You must configure the buffer address for EP0 to an address within the USB SRAM, ensuring that you place received data within the USB SRAM. The USB FS subsystem cannot access other memory locations in USB Keep-Alive mode. 

• Configure KEEP_ALIVE_WKCTRL[WAKE_ON_THIS] appropriately to configure what received token generates the wakeup from Keep-Alive mode. 

• Enable the wakeup interrupt by writing 1 to KEEP_ALIVE_CTRL[WAKE_INT_EN]. 

• Enable Keep-Alive mode operation by writing 1 to KEEP_ALIVE_CTRL[KEEP_ALIVE_EN]. 

## 2. Enter Sleep mode, ensuring that the USB 48 MHz functional clock source remains enabled:

• If the 48 MHz clock is not configured for USB crystal-less operation, follow Device mode FIRC operation instructions. 

• The software then enters Sleep mode, and the USB subsystem is in Keep-Alive mode. 

• Follow the procedures described in the "Power Management" and "System Power Control (SPC)" chapters of this document to reduce power consumption in Sleep mode for extraneous modules.
