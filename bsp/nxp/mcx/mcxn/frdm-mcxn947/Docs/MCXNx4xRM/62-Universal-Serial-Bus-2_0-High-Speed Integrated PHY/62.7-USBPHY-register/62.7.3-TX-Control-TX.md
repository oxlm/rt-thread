## 62.7.3 TX Control (TX)

## Offset

This type of register has supplemental _SET, _CLR, and _TOG registers at adjacent offsets. 

<table><tr><td>Register</td><td>Offset</td><td>Description</td></tr><tr><td>TX</td><td>10h</td><td>TX Control</td></tr><tr><td>TX_SET</td><td>14h</td><td>Writing 1 to a bit in this register ensures that the corresponding bit in TX is 1</td></tr><tr><td>TX_CLR</td><td>18h</td><td>Writing 1 to a bit in this register ensures that the corresponding bit in TX is 0</td></tr><tr><td>TX_TOG</td><td>1Ch</td><td>Writing 1 to a bit in this register inverts the value of the corresponding bit in TX</td></tr></table>

## Function

Allows adjustment of transmit circuit parameters.
