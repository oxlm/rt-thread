## 62.7.2 Power Down (PWD)

Offset 

This type of register has supplemental _SET, _CLR, and _TOG registers at adjacent offsets. 

<table><tr><td>Register</td><td>Offset</td><td>Description</td></tr><tr><td>PWD</td><td>0h</td><td>Power Down</td></tr><tr><td>PWD_SET</td><td>4h</td><td>Writing 1 to a bit in this register ensures that the corresponding bit in PWD is 1</td></tr><tr><td>PWD_CLR</td><td>8h</td><td>Writing 1 to a bit in this register ensures that the corresponding bit in PWD is 0</td></tr><tr><td>PWD_TOG</td><td>Ch</td><td>Writing 1 to a bit in this register inverts the value of the corresponding bit in PWD</td></tr></table>

## Function

Provides overall control and status indication of the USBPHY power state. 

The fields in this register have autopower-down writing of 1 and 0, depending on the configuration of fields in other registers. These features are intended to reduce the amount of software interaction needed when entering and leaving the Suspend bus state. 

You must enable USBPHY's main reference bias generator separately, including the specific bias circuits required for the PLL and those controlled with this register. See PLL_SIC[REFBIAS_PWD] and PLL_SIC[REFBIAS_PWD_SEL] for information regarding how the main reference bias is controlled. 

Before programming this register, you must enable the USBPHY clocks in USBPHY's General Purpose Control (CTRL) and PLL SIC (PLL_SIC)
