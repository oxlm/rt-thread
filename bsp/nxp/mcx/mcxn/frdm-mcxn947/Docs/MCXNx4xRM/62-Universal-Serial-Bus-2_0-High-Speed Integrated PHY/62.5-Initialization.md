## 62.5 Initialization

To initialize this module, USBPHY is designed for minimal configuration while retaining significant programmability. 


Table 493. USBPHY's configuration procedure


<table><tr><td>Step</td><td>Purpose</td><td>Programming</td></tr><tr><td>1</td><td>Release USBPHY from reset.</td><td>Write 0 to CTRL[SFTRST].</td></tr><tr><td>2</td><td>Run clocks.</td><td>Write 0 to CTRL[CLKGATE].</td></tr><tr><td>3</td><td>Reset the fields in Power Down (PWD).</td><td>Write 0 to the fields in Power Down (PWD).</td></tr><tr><td>4</td><td>Enable the UTMI+ level.</td><td>Write 1 to CTRL[ENUTMILEVEL2] and CTRL[ENUTMILEVEL3].</td></tr><tr><td>5</td><td>Enable other fields in General Purpose Control (CTRL) as needed.</td><td>Write 1 to CTRL[ENAUTOCLR_PHY_PWD], CTRL[ENAUTOCLR_CLKGATE], CTRL[AUTORESUME_EN], and so on.</td></tr><tr><td>6</td><td>Enable the reference clock system oscillator for the USB PLL.</td><td>Configure the reference clock system oscillator.</td></tr><tr><td>7</td><td>Control the USB PLL feedback loop divider.</td><td>Configure PLL_SIC[PLL_DIV_SEL] according to the system oscillator frequency.</td></tr><tr><td>8</td><td>Enable the USBPHY PLL regulator.</td><td>Write 1 to PLL_SIC[PLL_REG_ENABLE].</td></tr><tr><td>9</td><td>Clear the bypass feature.</td><td>Write 0 to PLL_SIC[PLL_BYPASS].</td></tr><tr><td>10</td><td>Configure other fields in PLL SIC (PLL_SIC) as needed.</td><td>Write to PLL SIC (PLL_SIC).</td></tr><tr><td>11</td><td>Power up the PLL.</td><td>Write 1 to PLL_SIC[PLL_POWER].</td></tr><tr><td>12</td><td>Enable the USB 3.3 V and 1.8 V monitors.</td><td>Write 1 to ANACTRL[LVI_EN].</td></tr><tr><td>13</td><td>Wait for the PLL clock lock.</td><td>Poll PLL_SIC[PLL_LOCK].</td></tr><tr><td>14</td><td>Enable the USB clock.</td><td>Write 1 to PLL_SIC[PLL_EN_USB_CLKS].</td></tr></table>
