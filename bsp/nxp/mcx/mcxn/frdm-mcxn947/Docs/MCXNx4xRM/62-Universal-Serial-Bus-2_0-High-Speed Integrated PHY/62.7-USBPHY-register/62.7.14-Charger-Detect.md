## 62.7.14 Charger Detect Status (USB1_CHRG_DET_STAT)

Offset 

This type of register has supplemental _SET, _CLR, and _TOG registers at adjacent offsets. 

<table><tr><td>Register</td><td>Offset</td><td>Description</td></tr><tr><td>USB1_CHRG_DET_STAT</td><td>F0h</td><td>Charger Detect Status</td></tr><tr><td>USB1_CHRG_DET_STAT_SET</td><td>F4h</td><td>Writing 1 to a bit in this register ensures that the corresponding bit in USB1_CHRG_DET_STAT is 1</td></tr><tr><td>USB1_CHRG_DET_STAT_CLR</td><td>F8h</td><td>Writing 1 to a bit in this register ensures that the corresponding bit in USB1_CHRG_DET_STAT is 0</td></tr><tr><td>USB1_CHRG_DET_STAT_TOG</td><td>FCh</td><td>Writing 1 to a bit in this register inverts the value of the corresponding bit in USB1_CHRG_DET_STAT</td></tr></table>

## Function

Allows observation of status for USB charger detection functions.
