## 62.7.11 VBUS Detect (USB1_VBUS_DETECT)

Offset 

This type of register has supplemental _SET, _CLR, and _TOG registers at adjacent offsets. 

<table><tr><td>Register</td><td>Offset</td><td>Description</td></tr><tr><td>USB1_VBUS_DETECT</td><td>C0h</td><td>VBUS Detect</td></tr><tr><td>USB1_VBUS_DETECT_SET</td><td>C4h</td><td>Writing 1 to a bit in this register ensures that the corresponding bit in USB1_VBUS_DETECT is 1</td></tr><tr><td>USB1_VBUS_DETECT_CLR</td><td>C8h</td><td>Writing 1 to a bit in this register ensures that the corresponding bit in USB1_VBUS_DETECT is 0</td></tr><tr><td>USB1_VBUS_DETECT_TOG</td><td>CCh</td><td>Writing 1 to a bit in this register inverts the value of the corresponding bit in USB1_VBUS_DETECT</td></tr></table>

## Function

Defines controls for several methods of USB VBUS detection and some additional out-of-band signaling functions.
