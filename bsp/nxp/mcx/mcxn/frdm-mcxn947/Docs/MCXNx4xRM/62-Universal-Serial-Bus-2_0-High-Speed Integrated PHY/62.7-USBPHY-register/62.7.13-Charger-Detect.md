## 62.7.13 Charger Detect (USB1_CHRG_DETECT)

## Offset

This type of register has supplemental _SET, _CLR, and _TOG registers at adjacent offsets. 

<table><tr><td>Register</td><td>Offset</td><td>Description</td></tr><tr><td>USB1_CHRG_DETECT</td><td>E0h</td><td>Charger Detect</td></tr><tr><td>USB1_CHRG_DETECT_SET</td><td>E4h</td><td>Writing 1 to a bit in this register ensures that the corresponding bit in USB1_CHRG_DETECT is 1</td></tr><tr><td>USB1_CHRG_DETECT_CLR</td><td>E8h</td><td>Writing 1 to a bit in this register ensures that the corresponding bit in USB1_CHRG_DETECT is 0</td></tr><tr><td>USB1_CHRG_DETECT_TOG</td><td>ECh</td><td>Writing 1 to a bit in this register inverts the value of the corresponding bit in USB1_CHRG_DETECT</td></tr></table>

## Function

Enables USB battery charging (BC) v1.2 functions, including device mode charger detection and host mode charging port advertisement. You can control several of the USBPHY analog circuits for BC v1.2 functions by either using this register or the embedded USBHSDCD module, which has autosequencing state machines and a separate register space. 

You must first enable USBPHY's main reference bias circuits for BC v1.2 functions by using either of the control methods (see MISC[REFBIAS_PWD] and MISC[REFBIAS_PWD_SEL]). 

See the "USB High-Speed Device Charger Detection (USBHSDCD)" chapter for USBHSDCD module operation.
