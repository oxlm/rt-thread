## 62.7.12 VBUS Detect Status (USB1_VBUS_DET_STAT)

## Offset

This type of register has supplemental _SET, _CLR, and _TOG registers at adjacent offsets. 

<table><tr><td>Register</td><td>Offset</td><td>Description</td></tr><tr><td>USB1_VBUS_DET_STAT</td><td>D0h</td><td>VBUS Detect Status</td></tr><tr><td>USB1_VBUS_DET_STAT_SET</td><td>D4h</td><td>Writing 1 to a bit in this register ensures that the corresponding bit in USB1_VBUS_DET_STAT is 1</td></tr><tr><td>USB1_VBUS_DET_STAT_CLR</td><td>D8h</td><td>Writing 1 to a bit in this register ensures that the corresponding bit in USB1_VBUS_DET_STAT is 0</td></tr><tr><td>USB1_VBUS_DET_STAT_TOG</td><td>DCh</td><td>Writing 1 to a bit in this register inverts the value of the corresponding bit in USB1_VBUS_DET_STAT</td></tr></table>

## Function

Allows observation of status for several different types of USB VBUS detect functions. 

This register also has a field to observe the external override signal for the OTG ID pin status.
