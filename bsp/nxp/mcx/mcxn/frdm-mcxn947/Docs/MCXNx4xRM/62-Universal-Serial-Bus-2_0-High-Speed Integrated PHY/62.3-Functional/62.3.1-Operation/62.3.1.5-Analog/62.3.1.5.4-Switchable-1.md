## 62.3.1.5.4 Switchable 1.5 kΩ USB_DP pullup resistor

USBPHY provides a switchable 1.5 kΩ pullup resistor on the USB_DP signal. This resistor is switched on to indicate to the host or hub controller that an FS-capable device is on the USB cable, powered on, and ready. This resistor is switched off at POR, so the host does not recognize a USB device until the processor software enables the announcement of an FS device.
