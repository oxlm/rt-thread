## 62.7.10 PLL SIC (PLL_SIC)

Offset 

This type of register has supplemental _SET, _CLR, and _TOG registers at adjacent offsets. 

<table><tr><td>Register</td><td>Offset</td><td>Description</td></tr><tr><td>PLL_SIC</td><td>A0h</td><td>PLL SIC</td></tr><tr><td>PLL_SIC_SET</td><td>A4h</td><td>Writing 1 to a bit in this register ensures that the corresponding bit in PLL_SIC is 1</td></tr><tr><td>PLL_SIC_CLR</td><td>A8h</td><td>Writing 1 to a bit in this register ensures that the corresponding bit in PLL_SIC is 0</td></tr><tr><td>PLL_SIC_TOG</td><td>ACh</td><td>Writing 1 to a bit in this register inverts the value of the corresponding bit in PLL_SIC</td></tr></table>

## Function

Configures the operation of USBPHY's 480 MHz PLL and observes its lock status. Use this register to control USBPHY's main reference bias generator used for PLL, transceiver, and detector circuits. Additional fields in the register are used to configure power mode switching features
