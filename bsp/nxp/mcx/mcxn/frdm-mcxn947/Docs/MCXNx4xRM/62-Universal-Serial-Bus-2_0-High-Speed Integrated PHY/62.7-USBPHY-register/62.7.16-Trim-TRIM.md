## 62.7.16 Trim (TRIM_OVERRIDE_EN)

Offset 

This type of register has supplemental _SET, _CLR, and _TOG registers at adjacent offsets. 

<table><tr><td>Register</td><td>Offset</td><td>Description</td></tr><tr><td>TRIM_OVERRIDE_EN</td><td>130h</td><td>Trim</td></tr><tr><td>TRIM_OVERRIDE_EN_SET</td><td>134h</td><td>Writing 1 to a bit in this register ensures that the corresponding bit in TRIM_OVERRIDE_EN is 1</td></tr><tr><td>TRIM_OVERRIDE_EN_CLR</td><td>138h</td><td>Writing 1 to a bit in this register ensures that the corresponding bit in TRIM_OVERRIDE_EN is 0</td></tr><tr><td>TRIM_OVERRIDE_EN_TOG</td><td>13Ch</td><td>Writing 1 to a bit in this register inverts the value of the corresponding bit in TRIM_OVERRIDE_EN</td></tr></table>

## Function

Allows observation of the default nonvolatile settings of USBPHY parameter controls for USBPHY_TX_CAL45DN, USBPHY_TX_CAL45DP, USBPHY_TX_D_CAL, and PLL_CTRL0_DIV_SEL. 

Additional fields also determine whether those values are overridden by using the settings defined in USBPHY's TX Control (TX) and PLL SIC (PLL_SIC). The default behavior is to use the values in TX Control (TX) and PLL SIC (PLL_SIC) instead of this register. 

The method used to load the read-only values into this register during reset and boot is chip-specific. The values observed in the read-only fields after boot may vary from the reset values shown.
