## 62.7.17 PFD A (PFDA)

## Offset

This type of register has supplemental _SET, _CLR, and _TOG registers at adjacent offsets. 

<table><tr><td>Register</td><td>Offset</td><td>Description</td></tr><tr><td>PFDA</td><td>140h</td><td>PFD A</td></tr><tr><td>PFDA_SET</td><td>144h</td><td>Writing 1 to a bit in this register ensures that the corresponding bit in PFDA is 1</td></tr><tr><td>PFDA_CLR</td><td>148h</td><td>Writing 1 to a bit in this register ensures that the corresponding bit in PFDA is 0</td></tr><tr><td>PFDA_TOG</td><td>14Ch</td><td>Writing 1 to a bit in this register inverts the value of the corresponding bit in PFDA</td></tr></table>

## Function

Includes fields for the PFD output clock. 

The PFD input clock comes from the 480 MHz USB PLL, and uses the PFD output clock (pfd_clk) to generate USB1PFDCLK for use outside USBPHY. 

There is 1 set of PFD controls and PFD output clock on this chip. 

ANACTRL[PFD_CLK_SEL] affects the PFD output clock behavior. 

To configure the PFD clock: 

1. Wait until PLL_SIC[PLL_LOCK] becomes 1. 

2. Configure ANACTRL[PFD_CLK_SEL] to select the PFD clock source. 

3. Configure PFDx_FRAC to select the PFD clock frequency. 

4. Write 0 to PFDx_CLKGATE to ungate the PFD clock. 

5. Wait until PFDx_STABLE becomes 1. 

Now you can use the PFD clock for system functions. 

## NOTE

If you want to change the value of PFDx_FRAC, gate the PFD clock (write 1 to PFDx_CLKGATE) and reset the PLL, that is, write 0 to PLL_SIC[PLL_POWER] and then write 1 to it again. After the reset, follow the aforementioned steps to reconfigure PFDx_FRAC.
