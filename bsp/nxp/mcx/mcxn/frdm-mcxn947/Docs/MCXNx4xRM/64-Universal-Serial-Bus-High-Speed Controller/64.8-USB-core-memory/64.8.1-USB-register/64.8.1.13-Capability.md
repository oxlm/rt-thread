## 64.8.1.13 Capability Registers Length (CAPLENGTH)

Offset 

<table><tr><td>Register</td><td>Offset</td></tr><tr><td>CAPLENGTH</td><td>100h</td></tr></table>

## Function

The Capability Registers Length register contains the address offset to the Operational registers relative to the CAPLENGTH register.
