## 64.3.3.4.3 Error interrupts

Error interrupts will be least frequent and should be placed last in the interrupt service routine. 

The following table shows the error interrupt events. 


Table 511. Error Interrupt Events


<table><tr><td>Interrupt</td><td>Action</td></tr><tr><td>USB Error Interrupt</td><td>This error is redundant because it combines USB Interrupt and an error status in the dTD. The DCD will more aptly handle packet-level errors by checking dTD status field upon receipt of USB Interrupt (w/ USB.ENDPTCOMPLETE).</td></tr><tr><td>System Error</td><td>Unrecoverable error. Immediate Reset of core; free transfers buffers in progress and restart the DCD.</td></tr></table>
