## 64.8.1.18 Device Controller Capability Parameters (DCCPARAMS)

Offset 

<table><tr><td>Register</td><td>Offset</td></tr><tr><td>DCCPARAMS</td><td>124h</td></tr></table>

## Function

These fields describe the overall device capability of the controller. 


NOTE



This register is only available in OTG controller core.
