## 64.3.3.4.2 Low-frequency interrupts

The low frequency interrupts can be handled in any order because they do not occur often in comparison to the highfrequency interrupts. 

The table below shows the Low frequency interrupt events. 


Table 510. Low Frequency Interrupt Events


<table><tr><td>Interrupt</td><td>Action</td></tr><tr><td>Port Change</td><td>Change software state information.</td></tr><tr><td>Sleep Enable (Suspend)</td><td>Change software state information. Low power handling as necessary.</td></tr><tr><td>Reset Received</td><td>Change software state information. Abort pending transfers.</td></tr></table>
