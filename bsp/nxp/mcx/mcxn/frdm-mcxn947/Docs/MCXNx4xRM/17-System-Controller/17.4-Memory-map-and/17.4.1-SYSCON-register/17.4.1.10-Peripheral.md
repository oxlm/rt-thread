## 17.4.1.10 Peripheral Reset Control 3 (PRESETCTRL3)

Offset 

<table><tr><td>Register</td><td>Offset</td></tr><tr><td>PRESETCTRL3</td><td>10Ch</td></tr></table>

## Function

The PRESETCTRL3 register allows software to reset specific peripherals. Writing a 0 to any assigned bit in this register clears the reset and allows the specified peripheral to operate. Writing a 1 asserts the reset. 

NOTE 

When modifying the PRESETCTRL registers, use the related PRESETCTRLSET and PRESETCTRLCLR registers to avoid setting or clearing bits unintentionally

17.4.1.11 Peripheral Reset Control Set (PRESETCTRLSET0 - PRESETCTRLSET3)



Offset


<table><tr><td>Register</td><td>Offset</td></tr><tr><td>PRESETCTRLSET0</td><td>120h</td></tr><tr><td>PRESETCTRLSET1</td><td>124h</td></tr><tr><td>PRESETCTRLSET2</td><td>128h</td></tr><tr><td>PRESETCTRLSET3</td><td>12Ch</td></tr></table>

## Function

Writing a 1 to a bit position in a write-only PRESETCTRLSETn register sets the corresponding position in PRESETCTRLn. 

NOTE 

To reset RTC correctly, you must write 1 to RTC.CTRL[SWR] when writing 1 to PRESETCTRL1[RTC_RST], and write 0 to RTC.CTRL[SWR] after writing 0 to PRESETCTRL1[RTC_RST].
