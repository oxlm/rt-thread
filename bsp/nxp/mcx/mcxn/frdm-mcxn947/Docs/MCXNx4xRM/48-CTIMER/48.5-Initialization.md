## 48.5 Initialization

To initialize CTIMER: 

1. Enable the clock to CTIMER. 

2. Write 0 to TCR[CRST]. 

3. Configure the interrupts. 

4. Connect the match outputs (see Match mode) to external pins and configure the related register (Match (MR0 - MR3)). 

5. Connect the capture inputs (see Capture mode) to external pins and configure the related register (Capture (CR0 - CR3)).
