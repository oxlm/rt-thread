## 48.7.3 Timer Control (TCR)

Offset 

<table><tr><td>Register</td><td>Offset</td></tr><tr><td>TCR</td><td>4h</td></tr></table>

## Function

Controls timer counter functions. You can disable or reset Timer Counter (TC) by using this register.
