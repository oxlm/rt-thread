## 63.3.2.4.1 SDP

As part of the charger detection handshake with a standard USB host, the module does the following without waiting for the interval (T<sub>WAIT_AFTER_PRD</sub> or T<sub>VDPSRC_CON</sub>) to elapse: 

• Updates the STATUS register to reflect that an SDP is detected with SEQ_RES = 01b. See Table 506 for field values. 

• Sets CONTROL[IF]. 

• Generates an interrupt if enabled in CONTROL[IE]. 

At this point, control is passed to system software via the interrupt. The rest of the sequence, which detects the type of charging port, is not applicable, so software must perform the following steps: 

1. Read the STATUS register. 

2. Set CONTROL[IACK] to acknowledge the interrupt. 

3. Set CONTROL[SR] to issue a software reset to the module. 

4. Disable the module. 

5. Communicate the appropriate charge rate to the external battery charger IC; see Table 495.
