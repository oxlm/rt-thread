## 63.3.1 Modes of operation

The operating modes of the USBDCD module are shown in the following table. 


Table 496. Module modes and their conditions


<table><tr><td>Module mode</td><td>Description</td><td>Conditions when used</td></tr><tr><td>Enabled for Charger Detection</td><td>The module performs the charger detection sequence.</td><td>System software must enable the module only if all of the following conditions are true:· The system is using a rechargeable battery or is otherwise capable of being powered up by an SDP or a Charging Port.· The device is being used in a USB device application.· The device is attached to the USB cable.</td></tr><tr><td>Enabled for Signal Overrides</td><td>Module bias circuits are enabled for special signaling on DP/DM pins.</td><td>See SIGNAL_OVERRIDE[PS].</td></tr><tr><td>Disabled</td><td>The module is not active and is held in a low-power state.</td><td>System software must disable the module when either of the following conditions is true:· The charger detect sequence is complete.· The conditions for being enabled are not met.</td></tr><tr><td>Powered Off</td><td>The digital supply voltage dvdd is removed.</td><td>Low system performance requirements allow putting the device into a very low-power stop mode.</td></tr></table>
