The timer is automatically initialized with the value of TSEQ_INIT before starting to count.This timer enables compliance with the maximum time allowed to connect <eq>T_{UNIT\_CON}</eq> under the USB Battery Charging Specification. If the timer reaches the one second limit, the module triggers an interrupt and sets the error flag STATUS[ERR].The timer continues counting throughout the charger detection sequence, even when control has been passed to software. As long as the module is active, the timer continues to count until it reaches the maximum value of FFFh (4095 ms). The timer does not roll over to zero.
