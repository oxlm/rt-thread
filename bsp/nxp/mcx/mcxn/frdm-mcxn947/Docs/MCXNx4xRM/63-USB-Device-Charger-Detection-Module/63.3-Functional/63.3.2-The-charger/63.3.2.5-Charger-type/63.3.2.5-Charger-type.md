## 63.3.2.5 Charger type detection

For USB Batter<sub>y</sub> Char<sub>g</sub>in<sub>g</sub> S<sub>p</sub>ecification Rev. 1.2: 

After the USBDCD module enables the V<sub>DM_SRC</sub>, the module starts the T<sub>VDMSRC_ON</sub> timer counting down the time interval programmed into the TIMER2[T<sub>VDMSRC_ON</sub>] field. 

Once the T<sub>VDMSRC_ON</sub> timer is elapsed, the module samples the USB D+ line to determine the type of charger. See the following table. 


Table 502. Sampling D+ in the charger type detection phase (BC1.2)


<table><tr><td>If the voltage on D+ is...</td><td>Then...</td><td>See...</td></tr><tr><td>High (D+&gt;VDAT_REF)</td><td>The port is a DCP.1</td><td>DCP</td></tr><tr><td>Low (D+&lt;VDAT_REF)</td><td>The port is a CDP.2</td><td>CDP</td></tr></table>


1. In a DCP, the D+ and D– lines are shorted together through a small resistor. 



2. In a CDP, the D+ and D– lines are not shorted. 


For USB Batter<sub>y</sub> Char<sub>g</sub>in<sub>g</sub> S<sub>p</sub>ecification Rev. 1. 1: 

After software enables the D+ pullup resistor, the module is notified automatically (via internal signaling) to start the CHECK_DM timer counting down the time interval programmed in the TIMER2[CHECK_DM] field. 

After the CHECK_DM time is elapsed, the module samples the USB D– line to determine the type of charger. See the following table. 


Table 503. Sampling D– in the charger type detection phase (BC1.1)


<table><tr><td>If the voltage on D- is...</td><td>Then...</td><td>See...</td></tr><tr><td>High</td><td>The port is a DCP.1</td><td>DCP</td></tr><tr><td>Low</td><td>The port is a CDP.2</td><td>CDP</td></tr></table>
