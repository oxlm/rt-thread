## 63.3.2.8 Host Mode CDP advertisement signaling

If the system is configured in Embedded Host mode, and the system hardware external to the SOC is capable of serving as a CDP, this capability can be signaled by the USBDCD module. 

As indicated in the USBBatter<sub>y</sub>Char<sub>g</sub>in<sub>g</sub> S<sub>p</sub>ecification Revision 1.2, one way that the CDP can behave for this case is to signal V<sub>DM_SRC</sub> on the USB_DM pin while there is not a remote device connected to the host, and then disable V<sub>DM_SRC</sub> shortly after a connection event. 

The V<sub>DM_SRC</sub> signaling can be enabled through setting the SIGNAL_OVERRIDE[PS] field to 100b. 

If this feature is used, the USB subsystem software must control this field upon detecting USB connect and disconnect events.
