## 26.5.1.64 DMA0 Request Enable2 (DMA0_REQ_ENABLE2)

Offset 

<table><tr><td>Register</td><td>Offset</td></tr><tr><td>DMA0_REQ_ENABLE2</td><td>720h</td></tr></table>

## Function

DMA request 64-95 enable for DMA0. One bit per request. 0: DMA request to DMA0 and response from DMA0 are blocked. 1:DMA request and response are enabled for DMA0.
