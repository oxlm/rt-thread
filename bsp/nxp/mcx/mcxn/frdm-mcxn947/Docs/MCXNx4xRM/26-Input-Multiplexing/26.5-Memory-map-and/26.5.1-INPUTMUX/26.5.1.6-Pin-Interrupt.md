## 26.5.1.6 Pin Interrupt Select (PINTSEL0 - PINTSEL7)

Offset 

For a = 0 to 7: 

<table><tr><td>Register</td><td>Offset</td></tr><tr><td>PINTSELa</td><td>C0h + (a × 4h)</td></tr></table>

## Function

Each of these eight registers selects one pin from among ports 0 and 1 as the source of a pin interrupt or as the input to the pattern match engine. To select a pin for any of the 8 pin interrupts or pattern match engine inputs, write the GPIO port pin number as 0 to 31 for pins P0_0 to P0_31 to the INP bits. Port 1 pins correspond to pin numbers 32 to 63. For example, setting INP to 0x5 in PINTSEL0 selects pin P0_5 for pin interrupt 0. To determine the GPIO port pin number for a given device package, see the pin description table in the data sheet.
