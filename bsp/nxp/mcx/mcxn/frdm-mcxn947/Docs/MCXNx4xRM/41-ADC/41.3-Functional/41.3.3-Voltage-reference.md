## 41.3.3 Voltage reference

The voltage reference high (V<sub>REFH</sub>) used by ADC is supplied from either an on-chip voltage reference source or from an off-chip source via external pins. V is always from an external pin and must be at the same voltage as the Analog Power Domain Ground. 

This block supports a programmable selection of the Voltage Reference High used for ADC conversions (via CFG[REFSEL]). 

See the chip configuration information on the voltage reference options specific to this packaged device.
